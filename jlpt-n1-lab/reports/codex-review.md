# 本批 120 题的 Codex 编辑复核

本次复核由当前对话中的 Codex（AI）完成，用户不需要逐题审核。它不同于本机 Qwen 9B 的批量盲答，也不是真人教师审校或官方认证。

共复核 120 道：50 道读音、50 道词汇填空、20 道语法。44 道修改了题干或选项；其余也核对并整理了解析。所有原稿保存在 `data/revisions/codex-full-review-v1/`。

## 复核范围与边界

- 将每个选项代入完整日语句子，检查接续、活用、语境、搭配和答案是否存在明显多解；核对中译与逐项解析。
- 删除以“更正式”“语气更强”为由强判合法选项错误的解析；有多解时改题或更换选项。
- 存疑规则查阅下方逐题记录中的词典或教学资料。资料仅支持对应词义或语法规则，不为本项目原创例句背书。没有声称全部例句都能在外部资料中逐字找到。
- 题目用于知识点巩固；部分干扰项较容易，不具备完整 N1 模拟卷的难度和区分度，也不能据此预测考试分数。AI 仍可能漏错。
- 本次复核没有启动或下载新的本地模型。原出题阶段的零付费模型 API 费用与耗时统计不包含当前 Codex 对话本身的使用成本。

## 使用方式

- 网页默认“复核练习”，可以直接做题，不再要求用户先审核。
- 用户收藏与 Codex 复核分开保存；没有为用户写入任何通过记录。原有 3 条答题记录保持不变，版本哈希仍区分新旧题。
- 提出疑问后本题暂时移出练习；在“全部题目”中清除个人标记可恢复。
- 修改题干、选项、答案、解析、中译或考点会使旧复核失效。复核题库导出为 `data/reviewed.json`，个人收藏仍导出为 `data/approved.json`。
